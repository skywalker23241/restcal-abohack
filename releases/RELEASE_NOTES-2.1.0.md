# 休历 RestCal v2.1.0

这是休历当前功能完整、可正式使用的版本，重点打通了日历记录与常用日历、邮箱之间的工作流，并完成了首次使用体验的整体优化。

## 主要更新

- Google 日历单向同步、系统日历导出与默认邮箱发送。
- 支持 Apple 日历、Google 日历、Outlook、飞书和企业微信的 ICS 导出。
- 新增往返火车票购票提醒和习惯打卡。
- 日、周、月视图使用不同层级的手写风格备注。
- 重做新手引导，以分块聚光介绍日历、记录、统计、工具和设置。
- 点击顶栏休历图标或文字，可直接返回今天的日视图。
- 优化移动端月视图、节假日插图和多处交互细节。

## 下载

- `RestCal-2.1.0-portable.exe`：Windows 免安装版。
- `RestCal-2.1.0-setup.exe`：Windows 安装版。
- `RestCal-2.1.0-win.zip`：Windows 解压版。
- `RestCal-2.1.0-android.apk`：Android 安装包（调试签名）。
- `SHA256SUMS-2.1.0.txt`：文件完整性校验。

Windows 构建暂未进行代码签名，首次运行时可能出现 SmartScreen 提示。Android APK 使用调试签名，适合直接安装体验。
