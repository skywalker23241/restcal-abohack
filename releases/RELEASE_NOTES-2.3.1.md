# 休历 RestCal v2.3.1

这是一个日视图视觉修复版本。

## 更新内容

- 恢复轻量平面日视图，移除 3D 旋转、叠页、翘角、支架和顶部装订点。
- Windows、Android 与网页端统一使用同一套样式。
- 更新 Service Worker 缓存版本，避免旧版样式残留。

## 发布文件

- `RestCal-2.3.1-portable.exe`：Windows 免安装版。
- `RestCal-2.3.1-setup.exe`：Windows 安装版。
- `RestCal-2.3.1-win.zip`：Windows 解压版。
- `RestCal-2.3.1-android.apk`：Android 安装包（调试签名）。
- `SHA256SUMS-2.3.1.txt`：文件完整性校验。
