# 休历 RestCal v2.3.0

本次更新重点完善跨端出行提醒、个性化主题和日视图体验。

## 主要变化

- 火车站支持中文、拼音、首字母和字母索引搜索；12306 链接自动填写往返车站与日期。
- 支持多个中转站排序、返程路线自动反转、逐段查询和官方换乘入口。
- 独立选择往返机场，覆盖 270 个内地运输机场，并提供国航、南航官网入口。
- 新增朱砂纸笺、竹影、晴海、暮紫四套配色，全部支持浅色与深色。
- 日视图采用轻量 CSS 台历样式，优化设置、日历导出、按钮、滚动条和移动端布局。
- 保留 v2.2.0 的模块化架构、Google 日历、工资核算与 WebDAV 稳定性修复。
