连接 Google 日历

使用系统浏览器完成安全授权

当前开发版本需要填写一次桌面应用类型的 OAuth 客户端 ID 与密钥。正式发行时可预置，普通用户无需看到此项。

如何创建客户端 ID

在 Google Cloud Console 启用 Google Calendar API，配置 OAuth 同意屏幕（把自己的账号加入测试用户），然后创建“桌面应用”类型的客户端，把生成的客户端 ID 和密钥一起填在上方。

Google 的桌面应用客户端虽然使用 PKCE，换取令牌时仍然必须带上密钥，否则会失败。Google 自身也说明安装类应用无法保守秘密，所以它不等同于账号密码；即便如此，它也和授权令牌一样加密保存在本机，不会进入备份或同步。
